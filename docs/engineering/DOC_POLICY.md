# 文档规范（DOC_POLICY.md）

## 1. 权威顺序

| 层级 | 文档 | 定位 |
|:----:|------|------|
| 1 | [README.md](../../README.md) | 对外事实源：定位、安装、最小 API 用法、核心语义。冲突时**以 README 为准** |
| 2 | `docs/spec/user-center-memory-chain.md` | 用户中心记忆链路（User-Center Memory Chain）的语义规范，spec 系列 Issue 落地 |
| 3 | [docs/engineering/](.) | 工程流程规范（本文系列）：流程、评审、CI、版本、分支 |
| 4 | [CONTRIBUTING.md](../../CONTRIBUTING.md) | 贡献者入口，只做导航，不重复规则细节 |
| 5 | [plan.md](../../plan.md)、[ROADMAP.md](../../ROADMAP.md) | 规划与路线，允许过期，阅读时以日期与状态标注为准 |
| 6 | [docs/architecture.md](../architecture.md) | **历史快照**（v1.0.x 时期），已带"历史文档"横幅，不作为现状依据 |

- 第 1、2 层互相冲突时：**以 README 为准**，并在 Issue 中记录待修一方。
- 第 2 层文档尚未合入仓库时，README 是唯一权威，其它文档不得引用不存在的 spec 章节。
- 第 4、5、6 层与上面冲突时，一律服从上层，并尽快修正或加横幅。

## 2. 禁止硬编码易过期计数

模块数、测试文件数、用例数、代码行数、覆盖率、commit 数一类数字**默认不写**。确有必要时，必须同时给出：

1. **统计口径**（统计什么、包含哪些目录）；
2. **统计命令或脚本来源**（可复现）；
3. **采样锚点**（commit SHA 或日期）。

正确写法：

```markdown
star_graph/ 顶层模块 127 个（`ls star_graph/*.py | wc -l`，统计于 f63648a）。
```

错误写法（历史教训：CONTRIBUTING 曾长期写"78 模块 / 33 测试文件 / 649 tests"，实际已严重偏离）：

```markdown
NWC 有 78 个模块，649 个测试全部通过。
```

- 徽章、README 表格等展示型数字同样受此约束；无法给出锚点的数字，宁可不写。
- 引用数字时注明来源文档与时间，避免二次传播后失真。

## 3. 链接规范

- 仓库内链接一律使用**相对路径**（`../../README.md`、`PR_POLICY.md`），不使用绝对路径、不使用 `blob/main` 之外的硬编码分支 URL。
- 链接目标必须存在；改名/移动文档时，同 PR 内修正全部入链（可用 `grep -rn "旧文件名" .` 自检）。
- 标题锚点使用小写连字符形式（GitHub 自动生成），避免频繁改标题导致断链。
- 外部链接写完整 `https://`，并优先引用官方文档。

## 4. 更新责任

- 代码行为、公开 API、配置默认值、CLI 参数变更：**同一个 PR** 内更新 README 与相关专题文档。
- 新增/删除脚本或工作流：同 PR 更新 [CI_POLICY.md](CI_POLICY.md) 的对应关系表。
- 新增流程或规则：同 PR 更新 [ENGINEERING.md](../../ENGINEERING.md) 的索引与硬规则。
- 文档 PR 也要过 CI 与双评审（B 评审专门核对文档同步）。

## 5. 过期与废弃

- 允许保留有历史价值的文档，但必须在文首加横幅，写明"历史文档 / 停留在哪个版本 / 以谁为准"（参照 [docs/architecture.md](../architecture.md) 的写法）。
- 整篇废弃时：优先加横幅 + 移入 `docs/archive/`（需新建 Issue，不静默删除）。
- 不允许"文档描述了不存在的脚本/工作流/参数"：不确定的实现细节只写接口意图，并注明"以脚本 `--help` / 实际文件为准"。

## 6. 语言与风格

- 以中文为主，术语（Issue / PR / squash / smoke / ratchet 等）保留英文。
- 规则用陈述句 + 可执行命令，避免"尽量""建议"模糊表述；确属建议的必须显式标注"建议"。
- 一页文档只回答一类问题；超过 200 行考虑拆分并在 [ENGINEERING.md](../../ENGINEERING.md) 登记。
